TwitchOverlay — Configuration initiale
Mise en place de l'overlay

À effectuer une seule fois. Durée estimée : 3 minutes.

1
Créer une application Twitch

Rendez-vous sur dev.twitch.tv/console/apps et connectez-vous avec votre compte Twitch, puis cliquez sur Register Your Application.

Donnez-lui le nom de votre choix. Dans le champ OAuth Redirect URLs, entrez exactement :
http://localhost:3000/auth/callback

Laissez la catégorie sur Other et validez.

2
Récupérer le Client ID et le Client Secret

Dans la liste de vos applications, cliquez sur Manage à côté de l'application que vous venez de créer.

Copiez le Client ID affiché en haut. Cliquez ensuite sur New Secret pour générer un Client Secret, puis copiez-le immédiatement — il n'est affiché qu'une seule fois.

3
Ajouter l'overlay dans OBS (après la configuration)

Une fois la configuration terminée, ajoutez une Source Navigateur dans OBS avec l'URL : http://localhost:3000/overlay.html

Dans la fenêtre de propriétés de la source, réglez bien les champs Largeur et Hauteur sur 1920 × 1080 (pas seulement la taille à laquelle vous l'étirez sur le canevas de la scène — sinon l'image sera floue), et cochez Actualiser le navigateur quand la scène devient active.

4
Renseigner vos informations
Le nom exact de la chaîne à surveiller (pas besoin de connaître l'ID, il est résolu automatiquement). L'objectif de subs se règle après coup dans le panel d'administration.
